ONBOARDING / AKUN BARU

Tambahkan penulis atau editor

  1. Buka Supabase Dashboard → Authentication → Users.
  2. Pilih Add user atau Invite user, lalu masukkan email anggota redaksi.
  3. Setelah akun dibuat/diundang, kembali ke dashboard FEBRIA MEDIA dan klik Muat ulang.
  4. Atur role anggota tersebut menjadi Penulis atau Editor pada daftar anggota di atas.
  5. Anggota menggunakan undangan atau kredensial yang disiapkan melalui Supabase untuk login ke dashboard.

Pembuatan akun dilakukan di Supabase Auth. Jangan meminta anggota mengirim password melalui chat dan jangan menaruh service_role key di website.
